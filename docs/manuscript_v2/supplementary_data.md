## Supplementary Data

## Supplementary Table 1. Top matching cell types from CellMarker 2024 library

The full ranked list of cell type similarities is provided in the supplementary Excel file:
[supplementary_tables/Supplementary_Table_1_CellMarker_2024.xlsx](supplementary_tables/Supplementary_Table_1_CellMarker_2024.xlsx). The dataset includes cell type name, tissue origin, species, distance metric, cosine similarity, embedding coverage, and marker gene mapping statistics.

## Supplementary Table 2. Top matching pathways from Reactome Pathways 2024

The full ranked pathway list is provided in the supplementary Excel file:
[supplementary_tables/Supplementary_Table_2_Reactome_Pathways_2024.xlsx](supplementary_tables/Supplementary_Table_2_Reactome_Pathways_2024.xlsx)

## Supplementary Table 3. Top matching drugs from DSigDB library

The complete ranked list of drug matches is available in the supplementary Excel file:
[supplementary_tables/Supplementary_Table_3_DSigDB.xlsx](supplementary_tables/Supplementary_Table_3_DSigDB.xlsx). The table includes the following columns: drug name, variance-weighted distance (lower values indicate greater similarity), cosine similarity (ranging from -1 to 1, with values closer to 1 indicating greater directional alignment), number of genes found in the drug signature that were successfully mapped to embeddings, and coverage (proportion of drug signature genes successfully mapped).

## Supplementary Table 4. Top Drug Perturbation Matches

The complete ranked list of drug perturbation matches is provided in the supplementary Excel file:
[supplementary_tables/Supplementary_Table_4_RummaGEO_DrugPerturbations_2025.xlsx](supplementary_tables/Supplementary_Table_4_RummaGEO_DrugPerturbations_2025.xlsx). The table includes drug signature identifiers, experimental descriptions, variance-weighted distance, cosine similarity, embedding coverage, and gene mapping statistics.
