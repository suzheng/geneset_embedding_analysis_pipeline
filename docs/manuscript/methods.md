# Methods

## Gene Set and Embeddings

The primary analysis unit for this study is a curated sepsis-associated gene set, representing a collection of gene symbols associated with the pathophysiology of sepsis. The gene list was obtained from a curated collection of sepsis-related genes, and the exact composition of the input gene set is recorded in the run metadata files. Prior to analysis, all gene symbols were normalized through a standardized procedure involving whitespace trimming, conversion to uppercase, and removal of empty entries. Genes that could not be mapped to the reference embedding space were excluded from downstream analysis.

Each gene symbol in the input set was mapped to a fixed-length vector representation using GeneRAIN embeddings, a transformer-based model trained on 410,000 human bulk RNA-seq samples via self-supervised learning. The GeneRAIN model learns gene representations that encode diverse biological attributes including protein domains, Gene Ontology terms, disease associations, pathway memberships, transcription factor targets, epigenetic marks, cell type markers, and protein-protein interactions. For this analysis, gene embeddings were retrieved from a precomputed embedding file containing 200-dimensional vectors, where each gene symbol corresponds to a vector of 200 continuous values representing the gene's learned functional characteristics in the embedding space.

## Signature Computation

The gene set was summarized as an embedding signature consisting of statistical summaries computed across all gene vectors in the embedding space. For each embedding dimension, two summary statistics were computed: a mean vector representing the centroid of the gene set, and a standard deviation vector capturing the within-set variability across dimensions. The mean vector was calculated as the per-dimension arithmetic mean across all gene vectors in the set, providing a central tendency measure that represents the collective functional profile of the gene set. The standard deviation vector was computed using Bessel's correction to estimate the sample standard deviation per dimension, quantifying the coherence or diversity of the gene set in each embedding dimension. To ensure numerical stability in downstream distance calculations, standard deviation values below 1×10⁻⁸ were clamped to this minimum threshold.

## Dimension Selection

To focus similarity calculations on the most stable and informative embedding dimensions, a variance-based filtering approach was applied. Dimensions with high variability across genes within the query set were down-weighted, as high variability indicates that genes are diverse in that particular semantic feature and may introduce noise into similarity comparisons. The analysis employed a quantile-based dimension selection method, retaining dimensions with standard deviation values at or below the 30th percentile of the standard deviation distribution across all dimensions. This filtering approach prioritizes dimensions where the gene set exhibits coherent behavior, thereby enhancing the signal-to-noise ratio in similarity matching while reducing the influence of noisy dimensions.

## Reference Gene Set Libraries

The query signature was compared against precomputed term signatures derived from curated gene set libraries selected for their clinical interpretability and relevance to sepsis pathophysiology. The primary analyses focused on five reference libraries: Reactome Pathways 2024, containing 2,076 pathway terms representing biological processes and signaling cascades; CellMarker 2024, containing 1,692 terms representing immune cell type markers and tissue-specific cell populations; DSigDB, containing 4,025 terms representing drug-related gene signatures; RummaGEO Drug Perturbations 2025, containing 5,344 terms representing drug perturbation signatures derived from Gene Expression Omnibus studies; and RNA-Seq Disease Gene and Drug Signatures from GEO, containing 1,302 terms representing disease-associated expression signatures and drug response profiles from published RNA-seq studies. These libraries were selected to enable interpretation of sepsis-associated genes in terms of biological pathways, immune cell types, potential drug repurposing opportunities, and comparisons to other disease signatures.

## Term Signature Precomputation

For each reference term in the selected libraries, the associated gene symbols were mapped into the same 200-dimensional GeneRAIN embedding space used for the query signature. Term-level signatures were precomputed by summarizing the gene vectors associated with each term using the same statistical approach applied to the query set: mean vectors representing term centroids and standard deviation vectors capturing within-term variability. This precomputation enabled direct comparison between the query signature and reference term signatures using consistent statistical summaries. Terms with fewer than five genes successfully mapped to embeddings were excluded from the reference database to ensure statistical reliability of the term signatures.

## Similarity Metrics and Ranking

Similarity between the query signature and reference term signatures was quantified using a variance-weighted distance metric that accounts for uncertainty in each embedding dimension. The variance-weighted distance weights each dimension by the inverse of the combined variance between the query signature and reference term signature, prioritizing dimensions with low variability where both signatures exhibit high confidence. Specifically, the distance was computed as the sum of weighted squared differences between mean vectors, where the weight for each dimension is inversely proportional to the sum of squared standard deviations from both signatures plus a small numerical stability constant. Smaller distance values indicate greater similarity between signatures.

As a complementary metric, cosine similarity was computed to assess directional alignment between the mean vectors of the query and reference signatures, independent of magnitude differences. Cosine similarity ranges from -1 to +1, with values closer to +1 indicating stronger directional alignment. Terms were ranked primarily by variance-weighted distance in ascending order, with cosine similarity used as a secondary criterion for tie-breaking. For each library, the top 20 most similar terms were retained for interpretation.

## Quality Control

Quality control procedures were implemented to assess data completeness and ensure reliable signature computation. Gene embedding coverage was calculated as the fraction of input genes successfully mapped to embeddings in the reference dictionary. Genes absent from the embedding space were tracked separately and excluded from signature computation. The pipeline recorded coverage metrics and diagnostic information for each analysis run. Additionally, the analysis pipeline produced tabular outputs and publication-quality figures for transparency and reproducibility, with each figure accompanied by corresponding data files containing the underlying numerical values used for visualization.

## Software and Reproducibility

All analyses were performed using Python 3.10.17 with NumPy version 2.2.6 and scikit-learn version 1.7.2. The analysis employed a fixed random seed of 17 for any stochastic operations to ensure reproducibility. Clustering analysis was disabled for this study, as the input gene set size was below the minimum threshold required for clustering. All run parameters, including dimension selection method, quantile thresholds, and ranking criteria, were recorded in run metadata files alongside timestamps and software version information. The complete parameter configuration and analysis outputs are preserved in the run artifacts to enable full reproducibility of the reported results.
